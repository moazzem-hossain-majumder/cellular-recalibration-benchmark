# Locked US replication protocol

This retrospective archive extension uses Drive 3 across every released carrier (AT&T, T-Mobile, Verizon). Drive 3 was chosen as the unused multi-day drive after the published Drive 2 development check. Use every matching downlink shard. Freeze the carrier-specific first ten complete pairs from its first two calendar dates, with all remaining dates held out. Reuse the Drive 2 minute clock, publisher transfer windows, signed order statistic and persistence baseline. Count abstentions, scored, positive, measured positive, observed failures, worst-case unresolved failures and supported throughput by carrier and date. Report empty and underpowered strata. Report every carrier; do not tune or pool carriers after scoring. The primary descriptive question is whether each carrier has higher failure among measured positive promises than across all measured opportunities. A gap is arithmetically expected when there are zero offers and any failures. Its magnitude and the supported rate are the quantities of practical interest. Carrier-dates from the same drive share exposure.

Assess raw schema and timestamp alignment separately before any full-feature tree claim. Fresh field data and an application acting on these forecasts would require new collection. This local analysis protocol is recorded before scoring Drive 3 and lacks an independently timestamped preregistration.
The raw AT&T Drive 3 header names all six serving-cell signal measurements with dBm/dB units. Before scoring, add a paired secondary analysis using the original 57-session Rome training split, defaults and seed, outdoor-driving scenario, last per-field signal strictly before issue within the same active interval and preceding minute, lag age and prior observed span. Calibrate each model separately on exactly the same ten labels and score on exactly the same ticks. Represent absent raw telemetry as missing, retain those ticks, and report availability by carrier/date. Also compare the frozen tree with all NR predictors masked at issue, holding its full-input calibration offset fixed. Record source gaps. Different instruments, rate endpoints and truncated US horizons limit equivalence.
## Prospective collection beyond the archived drive

Freeze one artifact hash and one primary comparison before the first new transfer. Log a scheduled attempt identifier, issue timestamp, clock synchronization error, transfer start and completion or failure code, bytes delivered at the fixed horizon, and the most recent eligible radio sample for each feature. Record a zero commitment and a no-lag abstention separately. Count every scheduled attempt and retain interrupted recordings. Specify in advance whether a failed service attempt counts as zero delivered throughput. Use the same transfers for tree and persistence. Keep carrier, date, route, handset and firmware identifiers so shared drive days can be clustered.

Define an operator's acceptable all-issued risk and minimum useful rate before collecting data; on positive offers, report honored and failed counts and conditional uncertainty. Plan coverage across independently scheduled dates, route types and operators. An illustrative independent-Bernoulli planning approximation around risk 10% needs about 139 positive offers for a 95% half-width of five percentage points. This is an optimistic lower bound under positive correlation. Inflate by the date-cluster design effect estimated on a separate pilot, account for the observed positive-offer frequency, and specify a fixed collection end date. At the E3 tree's 3/171 positive rate, 139 positive offers would require roughly 7,923 issued ticks even before clustering. Do not stop collecting when a preferred result appears.
