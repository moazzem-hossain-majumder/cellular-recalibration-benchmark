# Targeted reviewer baselines: frozen exploratory protocol

No new point predictor is trained. Use the same archived opportunities and initial ten successful labels. Run both predictors, all six cohorts, new-attempt caps 10 and 40, and Recorded, IID20_seed42, Burst20_seed42 feedback conditions from the existing timestamp-mask experiment. The single stress seed per mechanism limits generalization; the preceding seven-condition experiment remains available, and no stress seed was chosen for favorable baseline performance.

Controls are Frozen, Periodic, Early, ACI, original MARUR. Add three randomized schedules, DecayingOGD, pooled-score MARUR with its original pattern gate, and pooled-score MARUR without the gate. All use the same controller feedback access, delayed response semantics and conservative score p for unsuccessful responses. This yields 792 configurations. No modification to original saved results.

Random schedules draw a fixed seeded priority for every eligible opportunity and select the lowest C priorities before replay. They use only IDs, issue times and predictor availability; no outcomes. The same seed yields nested planned schedules across caps. Overlapping outstanding requests are skipped rather than replaced using future outcomes. Realized cost is reported, and equal-cap comparisons are excluded from matched-cost claims when costs differ. Seeds 42, 123, 2026 are all reported, never optimized. Full-roster scheduling is an offline nonadaptive comparator whose availability assumes the scheduled eligibility roster is known; it is not a deployable online active-learning algorithm.

DecayingOGD is a one-sided, delayed/sparse-feedback adaptation of the online quantile update studied by Angelopoulos, Barber and Bates, ICML 2024 (https://proceedings.mlr.press/v235/angelopoulos24a.html), not a reproduction of their experiments or theorem. It requests exactly the Periodic schedule, initializes q with the first ten-label conformal quantile and uses scale=max(1 Mbps, maximum absolute initial residual). After completed request j, update q <- q + scale*j^(-0.6)*(1{surrogate_score > q_at_issue}-0.1). Missing feedback uses the conservative score p. Issue max(0,p-q), without MARUR's pattern gate. No clipping of q and no tuning on test outcomes. Sparse, delayed and conservatively substituted feedback precludes transferring the published guarantee. Report failures as well as gains; 'stronger baseline' means a more recent methodological comparator, not presumed better performance.

Pattern experiments hold the original MARUR query schedule fixed. Pattern versus pooled changes only the residual subset used for the quantile; the pattern-support abstention gate remains enabled in both. The pooled/no-gate comparison then changes only that gate. Keep FIFO window ten and all age, pattern-trigger and budget settings fixed. Verify identical query IDs across these three variants. Separate this ablation from MARUR_NoPattern, which also changes triggering.

Report all cohorts/costs/scenarios, all-issued and positive-conditional risk bounds, offer frequency, abstention, supported throughput, query attempts, successful feedback and effective updates. The matched-offer decomposition is descriptive, not causal mediation. No hypothesis testing treating forecasts, seeds, carriers or repeated caps as independent trips; no post-hoc best policy promoted to confirmatory evidence.
