- `freeze_prospective_model.py`: Historical model-freezing script whose active 57-row Rome `HistGBM` artifact now resides at `results/pacer/frozen_rome_histgbm.joblib`.

- `refocus_manuscript.py` / `report_reviewer_revision.py`: Obsolete one-off reporting/refactoring helper scripts moved to archive.
